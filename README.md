# Мир маленьких гениев — первая рабочая версия (MVP 1.0)

Развивающее PWA-приложение для детей **3–7 лет** с лисёнком Лео и Енотиком.

## Что умеет

- Возрастные группы **3–4, 5–6, 6–7 лет**.
- Шесть игровых направлений: цвета и формы, счёт и числа, логика и внимание, звуки и слова, окружающий мир, дружба и доброта.
- **72 авторских задания**: 4 задания × 6 миров × 3 группы.
- После каждого ответа — мягкая обратная связь, можно исправить ошибку.
- Нет школьных отметок, таймеров и сравнения детей.
- Личная история посещённых игровых миров без регистрации — `localStorage` браузера.
- Иконка PWA, `manifest.webmanifest` и Service Worker (`sw.js`) для сохранения файлов офлайн.
- Кнопка «Послушать задание» использует локальный `speechSynthesis` браузера. Русская озвучка зависит от установленных голосов устройства, **офлайн не гарантируется**.
- Отдельный раздел для родителей с рекомендациями и удалением истории.

## Как проверить на компьютере

Самый простой способ — открыть отдельный файл `Мир_маленьких_гениев_предпросмотр.html` из комплекта поставки (в архив не входит). Он работает как локальная демонстрация, но **не устанавливается как PWA**.

Для проверки именно PWA нужно открыть проект с локального веб-сервера или опубликовать на HTTPS-сайте (например, GitHub Pages). Обычный двойной клик по `index.html` не активирует Service Worker.

## Как опубликовать через GitHub Desktop

1. Создайте **новый репозиторий** (не в репозитории «Читай-ка»): меню `File → New repository`, например `mir-malenkih-geniev`.
2. В GitHub Desktop нажмите `Repository → Show in Explorer`.
3. Перенесите **содержимое** архива в папку репозитория. `index.html`, `app.js`, `lessons.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `assets/`, `icons/` должны лежать в корне, а не в дополнительной вложенной папке.
4. В GitHub Desktop в поле `Summary` напишите `Первая версия Мира маленьких гениев`, нажмите `Commit to main`, затем `Publish repository` или `Push origin`. При публикации выберите публичный репозиторий, если хотите бесплатную открытую страницу GitHub Pages.
5. На сайте GitHub откройте `Settings → Pages → Build and deployment` и выберите `Deploy from a branch`, ветку `main`, папку `/(root)` → `Save`.
6. Ссылка будет вида `https://ВАШ-ЛОГИН.github.io/mir-malenkih-geniev/`. Публикация может занять несколько минут.

**Важно:** исходники открытого репозитория доступны другим людям. В приложении нет личных ключей, паролей или API-токенов.

## Установка на iPad и iPhone

1. С интернетом открыть опубликованный сайт в **Safari**.
2. Подождать до полной загрузки приложения и всех его файлов.
3. Нажать `Поделиться → На экран Домой → Добавить` (при наличии включить «Открыть как веб-приложение»).
4. Запустить иконку с главного экрана, затем включить авиарежим **и отключить Wi‑Fi** и проверить, открывается ли задание.

Офлайн-работа обеспечивается кешем браузера, который ОС может очистить. Обновления публикуются по тому же адресу после загрузки файлов и увеличения версии кеша в `sw.js`. История игр локальная и не синхронизируется между устройствами.

## Методическая основа и ограничения

Задания ориентированы на игровую форму познавательного, речевого и социально-коммуникативного развития с учётом возрастных этапов, описанных в российских документах:

- [Федеральная образовательная программа дошкольного образования, приказ Минпросвещения № 1028](https://docs.edu.gov.ru/document/0e6ad380fc69dd72b6065672830540ac/).
- [Федеральный государственный образовательный стандарт дошкольного образования, приказ № 1155](https://docs.edu.gov.ru/document/a72db92c851c9f9c33d52d482420b477/).

Это **не образовательная программа детского сада**, не медицинская и не педагогическая диагностика, не полноценный охват всех пяти образовательных областей. Пилотные задания целесообразно дать на рецензию практикующему педагогу дошкольного образования до широкого запуска. Физическую активность и художественное творчество цифровые задания не заменяют. Для детей 3–4 лет рекомендуется совместная игра со взрослым.

**ИИ-чат пока не подключён:** это сознательно отложено до отдельной безопасной реализации с интернет-подключением, серверной защитой ключей и специальными правилами для детской аудитории. Всё текущее содержимое офлайн и не требует внешних сервисов.

## Технические детали

- Статические HTML, CSS и JavaScript, без сборщиков, фреймворков, серверного API и рекламы.
- Все картинки, иконки и задания внутри проекта.
- Для релиза обновите `CACHE_NAME` в `sw.js`, чтобы заменились сохранённые файлы.
- Данные хранятся только в текущем браузере/установке приложения (Web Storage) и могут исчезнуть при очистке.
- Service Worker регистрируется только на `https:` или `localhost`.
